# Notification Management

AcmeCloud allows users to control how they receive notifications.

## Email Notifications

Users can enable or disable email notifications from Notification Settings.

Changes to email notification preferences take effect immediately.

## Notification Digest

Users can configure a daily notification digest from Notification Settings.

The daily digest combines eligible notifications into a single email.

## Muting Notifications

Users can mute notifications for a specific project.

Muted project notifications are not included in the user's regular notification feed.

Users can unmute a project at any time from the project notification settings.

## Security Alerts

Security alerts cannot be muted.

AcmeCloud always sends security alerts when a security-sensitive event requires the user's attention.
